# CAFFENA - Coffee Shop Landing Page

A responsive landing page for a coffee shop, built as a front-end practice
project. It presents the shop, its menu and products, customer reviews, and
blog posts in a single-page layout.

## Sections

- Hero with animated headline
- About ("What Makes Our Coffee Special?")
- Menu and product cards with prices
- Customer reviews
- Blog preview cards and contact/footer area

## Tech Stack

- HTML5, CSS3
- Bootstrap and custom CSS animations
- JavaScript with WOW.js scroll animations
- Font Awesome icons

## Run It

No build step is needed. Open `index.html` in a browser, or serve the folder
with any static server.
